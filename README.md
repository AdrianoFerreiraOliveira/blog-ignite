<h1>Blog Ignite</h1>

<p>Blog Ignite is a web application that allows users to view and interact with blog posts. The project is built using modern web development tools, including Vite and JavaScript, to provide a fast and responsive user experience.</p>

<h2>📂 Project Structure</h2>

<pre>
📂 blog-ignite
 ├── 📁 src                   # Source code for the blog application
 ├── index.html               # Main HTML file
 ├── package.json             # Project dependencies and scripts
 ├── package-lock.json        # Lock file for dependency versions
 └── vite.config.js           # Vite configuration for the project
</pre>

<h2>🔨 Features</h2>

<ul>
  <li>Display blog posts with title, content, and images.</li>
  <li>Responsive design for mobile and desktop devices.</li>
</ul>

<h2>🛠️ How to Run the Project</h2>

<ol>
  <li>Clone the repository:
    <pre><code>git clone https://github.com/AdrianoFerreiraOliveira/blog-ignite.git</code></pre>
  </li>
  <li>Navigate to the project directory:
    <pre><code>cd blog-ignite</code></pre>
  </li>
  <li>Install the dependencies:
    <pre><code>npm install</code></pre>
  </li>
  <li>Run the development server:
    <pre><code>npm run dev</code></pre>
  </li>
</ol>

<h2>✔️ Technologies Used</h2>

<ul>
  <li><strong>Vite</strong>: Fast build tool for modern web projects.</li>
  <li><strong>JavaScript</strong>: Core programming language for the application.</li>
  <li><strong>HTML/CSS</strong>: Used for structure and styling of the web pages.</li>
</ul>

<h2>🚀 Deployment</h2>

<p>The application can be deployed using Vite's default configuration. Check out the project by running it locally or deploying it on a hosting platform like Vercel.</p>
